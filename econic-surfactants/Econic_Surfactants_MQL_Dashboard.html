How to update this dashboard monthly

  1. Update REPORT_PERIOD and CURRENT_MONTH at top of script
  2. Add new campaign to CAMPAIGNS object
  3. For each contact with new engagement, add a row to their engagements array — do not delete old rows
  4. For new web form subscribers, add a new contact block with web_form: true in their engagement
  5. Save and reload — everything recalculates automatically
